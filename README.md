# Rajendra S — Portfolio

Personal portfolio site (Next.js) for **Rajendra S**, Senior Full Stack Developer.

## Stack

- Next.js (App Router), React, TypeScript, Tailwind CSS
- Content in `lib/site-config.ts`, `lib/about-content.ts`, `lib/home-content.ts`
- ATS résumé PDF: `npm run generate:resume` → `public/resume.pdf`

## Scripts

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # copies resume PDF, then production build
npm run generate:resume
```
